# My To-Do List

Simple responsive to-do list built with only HTML, CSS and vanilla JavaScript.

Features
- Add tasks with priority (High, Medium, Low).
- Checkbox to mark completed tasks (shows strikethrough).
- Edit and Delete tasks.
- Counts for completed and incomplete tasks.
- Clear Completed and Clear All (confirmation) buttons.
- Persists tasks to browser localStorage.
- Responsive and accessible UI.

How to open locally

- Open `index.html` in your browser (double-click the file).
- Or run a simple static server (optional):

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Notes
- Uses no libraries or build tools. Keep all three files in the same folder.
- To reset stored tasks delete the `todoTasks_v1` key from browser DevTools -> Application -> Local Storage.
